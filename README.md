## 🥛 Overview

This is a premium, modern, lightweight, and mobile-first informational business website for **Kailash Kamdhenu Dairy Farm**. 

The farm produces 100% pure raw A2 milk and traditional Vedic Bilona Desi Ghee from **25 indigenous Sahiwal and Gir cows** grazing in natural open paddocks at Bariyarpur, Deoria.

**Key Architecture Highlights:**
- **No unnecessary ecommerce complexity:** No shopping cart, no customer login, no database dependency, no payment gateway fees.
- **Direct WhatsApp & Phone Ordering:** Every product card and contact form dynamically generates pre-filled WhatsApp messages with the selected product, quantity, customer address, and delivery schedule.
- **Bilingual (Hindi / English):** Full native dual-language toggle with natural, culturally resonant Hindi translations.
- **Local SEO & Structured Data:** Pre-configured JSON-LD Schema.org `DairyFarm` markup targeting Deoria and Gorakhpur searches.

## 📄 Website Structure & Pages

1. **Home Page (`/`)**
   - Hero section with Sahiwal and Gir cow photography, sacred badge, and CTA buttons.
   - Heading: *"Shuddh Doodh, Saccha Vishwas."*
   - Subtitle: *"Pure A2 Milk & Traditional Desi Ghee, Directly From Our Farm to Your Home."*
   - WhatsApp Order & Direct Call buttons.
   - 6 Trust Indicators: 25 Desi Cows, Farm Fresh, No Added Water, No Milk Powder, Calves Fed First, Vedic Bilona Ghee.
   - Featured interactive product cards with real-time quantity switcher.
   - Sahiwal and Gir cow breed spotlight with characteristics and milk quality facts.
   - 4-Pillar Quality Assurance & 5-Step Ancient Vedic Bilona Ghee timeline.
   - Genuine customer testimonials from Deoria and Gorakhpur residents.

   - Interactive Order & Enquiry Form that opens WhatsApp with a formatted message containing the customer's name, phone, city, delivery address, product, and instructions.

## 🚀 How to Run Locally

### 1. Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build & Start
```bash
npm run build
npm run start
```
